# Shopify Product CSV Generator — Cricket Graphic T‑Shirts

> This is the documentation for the standalone CSV tool that lives in this folder.
> The website (storefront + admin area) is documented in [`README.md`](README.md).
> The two share nothing but the folder: the generator needs no packages and does not
> touch the store's database.

A beginner‑friendly Python program that turns your product details into a CSV file you can upload straight into Shopify:

> Shopify Admin → Products → Import products → Upload file

It produces one variant row per size (XS, S, M, L, XL, 2XL), uses Shopify's **current official product CSV headers**, validates everything you type, and never invents image URLs, SKUs or stock levels.

## 2. Installation

**You do not need to install anything.** The program uses only the Python standard library — no `pip install`, no virtual environment, no packages.

Just confirm Python is installed:

```bash
python --version
```

You need **Python 3.8 or newer**. If you do not have it, download the installer from <https://www.python.org/downloads/> and tick **"Add Python to PATH"** during setup.

> On some Windows machines the command is `py` instead of `python`. If `python` is not found, use `py` for every command below.

```bash

# Run the test suites

python test_edge_cases.py
```

## 4. Step‑by‑step: what the program asks you

For each product you will be asked:

| # | Prompt | Notes |
|---|---|---|
| 1 | **Product title** | e.g. `Rohit Sharma Sixes Graphic T-Shirt` |
| 2 | **Description** | Type as many lines as you like. Press **Enter on an empty line** to finish. Commas, `"` quotes and line breaks are all handled correctly. |
| 3 | **Price (INR)** | `799`, `799.50`, `Rs 799`, `1,299.00` all work. Must be greater than 0. |
| 4 | **Image URL** | A public `http://` or `https://` link. Press Enter on an empty line to stop adding images. |
| 5 | **Vendor name** | e.g. `Cricket Threads` |
| 6 | **Available sizes** | Any mix of `XS, S, M, L, XL, 2XL`. Anything else is rejected. |
| 7 | **Inventory quantity per size** | Asked once per size you selected. Negative numbers are rejected. |
| 8 | **SKU per size** | Optional. Leave blank and it stays blank in the CSV — nothing is made up. |
| 9 | **Product tags** | Default: `Cricket, T-Shirt, Graphic Tee` |
| 10 | **Product status** | `active` or `draft` |

Then you are asked whether to **add another product to the same file**, and whether to **add optional details** (URL handle, compare‑at price, cost per item, weight in grams, SEO title/description, collection name, and a per‑size price override). Every optional prompt can be skipped with Enter.

When you are done, the program prints a summary of every product and variant, plus the absolute path of the file it wrote.

### How to read that

* **Row 1** carries the product info (Title, Description, Vendor, Tags…) **plus the first variant and the first image**.
* **Rows 2‑6** repeat only the `URL handle` and that row's variant data.
* Shopify groups the rows together because the `URL handle` is identical.
* `Option1 name` is always `Size`; `Option1 value` is the size.
* `Option1 name` is repeated on **every** variant row on purpose. Shopify's own
  export leaves it blank on continuation rows, but writing it everywhere is
  unambiguous — the option structure can never be misread, and it prevents
  Shopify from creating a stray "Default Title" variant. Either style imports
  correctly; this one is the safer of the two.
* `"` inside the description becomes `""` — that is standard CSV escaping and Shopify reads it back as a single quote character.
* The `Collection` column only appears if you actually use a collection name. (`Collection` is the one extra column Shopify permits.)

## 7. Uploading to Shopify

1. Run `python shopify_csv_generator.py` and finish the wizard.
2. Open `shopify_products.csv` in Excel or Google Sheets and eyeball it (optional but recommended).
3. In Shopify: **Products → Import products → Upload file**.
4. Upload `shopify_products.csv`.
5. Review the **import preview** Shopify shows you, then confirm.
6. Optional: tick **"Overwrite products with matching handles"** if you are re‑importing a file for products that already exist and you want the CSV values to replace the current ones.

## 8. Why there is no `shopify.size` metafield column

This is the most common reason a Shopify product CSV import fails.

When you assign a **product category** such as `Apparel & Accessories > Clothing > Clothing Tops > T-Shirts`, Shopify automatically offers **category metafields** for it — including `size`, `neckline`, `sleeve length type`, `top length type`, `age group`, `fabric`, `target gender`, `clothing features` and `color`.

Those metafields expect **metaobject handles or GIDs**, not plain text. So a column like this is invalid:

```
Size (product.metafields.shopify.size)      <-- values must be handles/GIDs, not "M"
```

and so is an `Option1 Linked To` column pointing at `product.metafields.shopify.size`.

**What this program does instead:**

* It **never writes any metafield column.** No `product.metafields.*` headers, no `Option Linked To` columns. That is what prevents the `shopify.size` metafield error.
* The size is written as a plain, standard option: `Option1 name` = `Size`, `Option1 value` = `M`. This always works.
* The `Product category` column is a **normal Shopify column**, not a metafield. It is filled with a valid *category breadcrumb* from Shopify's Standard Product Taxonomy (breadcrumbs are used instead of numeric category IDs because the IDs get renumbered between taxonomy releases).
* If you want the real `size` category metafield filled in, do it in the Shopify admin after import: **Products → your product → Category metafields**. Shopify will offer the size list and you can map `XS, S, M, L, XL, 2XL` onto it.

## 9. What the program refuses to do

* **It never invents image URLs.** You must supply each URL yourself, and it must start with `http://` or `https://`. It also rejects `_thumb`, `_small` and `_medium` file names, because Shopify re‑uploads the original.
* **It never invents SKUs.** Leave the SKU prompt blank and the cell is blank in the CSV.
* **It never invents supplier stock.** The quantity is exactly what you typed. It will not contact a supplier, and it does not claim to fulfil orders.
* **It will not let you sell stock you do not have.** Negative quantities are rejected.
* **It rejects duplicate SKUs and duplicate URL handles** across the whole file, because Shopify refuses those.

## 10. ⚠️ Importing is NOT supplier fulfilment — read this

**Importing a CSV into Shopify only creates catalogue products in your store.** Nothing more.

It does **not**:

* connect your products to Printful, Printify, Gelato, TeePublic or any other print‑on‑demand supplier,
* push the designs to the supplier's printing pipeline,
* sync stock levels with the supplier,
* create a fulfillment service in Shopify,
* fulfil or ship any order.

In the generated CSV every variant is deliberately set to:

```
Fulfillment service  = manual
Inventory tracker    = shopify
```

`manual` is Shopify's built‑in manual fulfilment method. That is intentional: it means *you* (or a supplier app) handle the order.

### To actually automate dropshipping you must set this up separately

1. **Install a supplier app** from the Shopify App Store (Printful, Printify, Gelato, etc.).
2. **In that app**, create your products or map the imported Shopify products to supplier products, and upload the artwork for each design.
3. **Turn on order syncing** in the app so new Shopify orders are sent to the supplier.
4. **Turn on fulfilment** so the app pushes orders back to Shopify with tracking numbers.
5. **Set the product's fulfilment service** to the supplier's service inside Shopify (it appears in the product's **Inventory** section once the app creates it).
6. **Decide how stock is tracked.** The `Inventory quantity` column in a product CSV only applies to stores with a **single location**. If you have multiple locations, use the separate inventory CSV that Shopify offers. For made‑to‑order print‑on‑demand, it is usually best to let the supplier app own the stock and set the quantity to `0` or leave inventory untracked.

Until steps 1–5 are done, a customer order will sit in your Shopify admin as an unfulfilled order that only you can fulfil by hand.

## 11. Column reference

Columns written by the program, in the order they appear in the file. Every one is an official Shopify product CSV header.

| Column | Value used |
|---|---|
| `Title` | Your product title |
| `URL handle` | Auto‑generated from the title (`rohit-sharma-sixes-graphic-t-shirt`), editable |
| `Description` | Your description, line breaks preserved |
| `Vendor` | Your vendor name |
| `Product category` | A valid taxonomy breadcrumb (see section 8) |
| `Type` | `Graphic T-Shirt` |
| `Tags` | `Cricket, T-Shirt, Graphic Tee` |
| `Published on online store` | `TRUE` / `FALSE` |
| `Status` | `active` / `draft` |
| `SKU` | Your SKU, or blank |
| `Variant Barcodes` | Blank (leave blank unless you have barcodes) |
| `Option1 name` | `Size` |
| `Option1 value` | `XS`, `S`, `M`, `L`, `XL`, `2XL` |
| `Price` | `799.00` (no currency symbol) |
| `Compare-at price` | Optional |
| `Cost per item` | Optional |
| `Charge tax` | `TRUE` |
| `Inventory tracker` | `shopify` (or blank if you turn tracking off) |
| `Inventory quantity` | Your number, `0` or more |
| `Continue selling when out of stock` | `deny` |
| `Weight value (grams)` | Default `200`, editable |
| `Weight unit for display` | `g` |
| `Requires shipping` | `TRUE` |
| `Fulfillment service` | `manual` |
| `Product image URL` | Your public image URL |
| `Image position` | `1`, `2`, `3`… |
| `Image alt text` | Auto‑generated from the title |
| `Variant image URL` | Blank unless you assign a size‑specific image |
| `Gift card` | `FALSE` |
| `SEO title` | Your SEO title, max 70 chars |
| `SEO description` | Your SEO description, max 320 chars |
| `Collection` | Only if you use one (the one column Shopify allows you to add) |

Deliberately **not** written: all `product.metafields.*` columns, all `Option Linked To` columns, `Tax code`, the `Unit price …` columns, `Option2`/`Option3` (you only need one option, `Size`), the `Google Shopping / …` columns and the `Packed product …` columns. All of those are optional; leaving them out means Shopify applies its own defaults.

## 12. Encoding and file format

* UTF‑8 **without** a BOM (a BOM would break the first column name, `Title`).
* LF (`\n`) line endings, as Shopify requires.
* Standard RFC 4180 quoting, so commas, double quotes and line breaks inside a description are all safe.
* Written with Python's `csv` module, then re‑read and structurally verified by the program before it reports success.

## 13. Troubleshooting

| Problem | Fix |
|---|---|
| `python` is not recognized | Install Python from python.org and tick "Add Python to PATH", or use `py` instead of `python`. |
| "Image URL must start with http:// or https://" | Your image is on your computer. Upload it to Shopify **Content → Files** (or any public host) and copy the link. |
| Import says the product was skipped | Check the Shopify import preview — it names the row and the reason. Run `python shopify_csv_generator.py --validate yourfile.csv` first. |
| Images did not appear | Shopify downloads images from the URL during the import. The URL must be publicly reachable and must not require a login. |
| Prices show as 0 | `Price` must contain only the number, with no `₹` or `Rs`. The program already strips those. |
| Stock shows 0 | `Inventory quantity` in a product CSV only applies to **single‑location** stores. With multiple locations, use Shopify's inventory CSV or the supplier app. |
| I want a different file name | `python shopify_csv_generator.py --output my_tees.csv` |
